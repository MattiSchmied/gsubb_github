# Grundschule Unterbiberg – GitHub-Pages-Dateien

Dieser Ordner enthält die fertige statische Website. Die Seiten, Bilder, Navigation und Suche funktionieren ohne PHP oder Datenbank.

## Einfach veröffentlichen

1. Lege auf GitHub ein eigenes Repository für die Website an, zum Beispiel `GSUbb-Website`. Ein separates Repository lässt den bestehenden PHP-Quellcode unberührt.
2. Lade **den Inhalt dieses Ordners** in den obersten Ordner des neuen Repositories hoch. `index.html` und `.nojekyll` müssen direkt dort liegen.
3. Öffne im Repository **Settings → Pages**. Wähle bei **Build and deployment** die Quelle **Deploy from a branch**, dann den Branch `main` und den Ordner `/(root)`. Speichere die Einstellung.
4. Nach der Veröffentlichung findest du die Website unter `https://<dein-benutzername>.github.io/<repository-name>/`.

Für GitHub Pages muss das Website-Repository bei einem kostenlosen GitHub-Konto öffentlich sein. GitHub Pages veröffentlicht die Website für alle; lade deshalb nur Inhalte hoch, die öffentlich auf der Schulwebsite erscheinen sollen. Die GitHub-Dokumentation erklärt die [Veröffentlichungsquelle](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) und [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages).

## Lokal ansehen

`index.html` doppelklicken. Die Suche und alle Seitenlinks funktionieren auch beim lokalen Öffnen.
